# src-tauri/binaries

Tauri 2 `bundle.externalBin` input directory for the compiled Cordis host
("sidecar"). The build artifact is **not committed** (git-ignored); it is
generated by:

```sh
bun run build:host                 # host Rust target triple
bun run build:host -- --target-triple <triple>   # explicit cross target
```

Tauri requires the input file named `host-<rust-target-triple>[.exe]`
(logical name `binaries/host`). The mapping Rust triple → Bun compile target
lives in `scripts/build-host.ts` (add rows there for new platforms; do not
hard-code Windows x64 in callers).

At `cargo tauri build` time Tauri renames the sidecar inside the bundle to
`host[.exe]` (triple suffix stripped) next to the main executable; the shell
resolver (`src-tauri/src/host.rs`, `resolve_host_launch`) probes
`resource_dir()` for the packaged name and falls back to the dev source
launch. Runtime `cordis.yml` / `plugins/` are intentionally **not bundled**
yet (M1 scope): install the host runtime directory next to the app or use
`VRCXK_HOST_BIN` for now.
